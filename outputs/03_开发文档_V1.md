## 2. 开发环境

开发机需要：

- Windows 10/11 x64。
- Python 3.12.10 x64。
- Git。
- Inno Setup 6.7.3，仅用于构建安装包。
- 网络，仅首次拉取依赖和制作 wheelhouse 需要。

目标用户机器不需要安装以上内容。

## 4. 入口设计

`src/pdf_guard/__main__.py`：

- 初始化日志。
- 检查运行环境。
- 加载用户配置。
- 启动 Tkinter 主窗口。

主窗口只处理 UI 事件，不直接操作 PDF。所有 PDF 操作通过 `AppService` 调用。

## 5. 核心数据模型

```python
@dataclass
class RedactionBox:
    page_index: int
    rect: tuple[float, float, float, float]

    category: str

@dataclass
class ProcessOptions:
    input_path: Path
    output_path: Path
    open_password: str | None
    owner_password: str
    user_password: str | None
    redact_boxes: list[RedactionBox]
    watermark: WatermarkOptions
    flatten: bool
    flatten_dpi: int
    permissions: PermissionOptions
```

## 6. 规则引擎

规则接口：

```python
class PatternRule(Protocol):
    name: str
    category: str
    def finditer(self, text: str) -> Iterable[MatchResult]: ...
```

默认规则：

- 手机号：避免误匹配长数字的一部分。
- 身份证号：支持 18 位，末位 X/x。
- 邮箱：常见邮箱格式。
- 银行卡：13-19 位数字，V1 可加 Luhn 校验。
- 统一社会信用代码：18 位数字和大写字母。
- 自定义关键词：精确匹配。

## 7. PDF 预览

预览模块职责：

- 用 PyMuPDF 将当前页渲染为 pixmap。
- 用 Pillow 转为 `ImageTk.PhotoImage`。
- 在 Canvas 上绘制页面图。
- 绘制候选脱敏框。
- 捕获鼠标拖拽生成手动框。

坐标转换必须单独写测试。

## 8. 处理服务伪代码

```python
def process_pdf(options: ProcessOptions) -> ProcessReport:
    work = create_temp_workspace()
    redacted_path = work / "01_redacted.pdf"
    watermarked_path = work / "02_watermarked.pdf"
    flattened_path = work / "03_flattened.pdf"

    doc = open_pdf(options.input_path, options.open_password)
    apply_redactions(doc, options.redact_boxes)
    sanitize_document(doc, clear_bookmarks=True)
    add_watermark(doc, options.watermark)
    doc.save(watermarked_path)
    doc.close()

    source_for_encrypt = watermarked_path
    if options.flatten:
        rasterize_to_pdf(watermarked_path, flattened_path, dpi=options.flatten_dpi)
        source_for_encrypt = flattened_path

    encrypt_with_permissions(
        source_for_encrypt,
        options.output_path,
        owner_password=options.owner_password,
        user_password=options.user_password or "",
        permissions=options.permissions,
    )

    return verify_output(options.output_path, options)
```

## 9. 测试策略

### 集成测试

- 文本型 PDF 自动脱敏后无法提取原手机号。
- 手动框选后区域不可复制。
- 加水印后页面可见水印。
- 压平输出后文本层为空或只包含允许文本。
- 权限密码设置后普通阅读器禁止复制/修改。

### 冒烟测试

- `sample_text_sensitive.pdf`

- `sample_encrypted_open_password.pdf`
- `sample_large_100_pages.pdf`

## 10. 编码规则

- UI、业务、PDF 处理分离。
- 不在 UI 回调里直接写 PDF。
- 不记录敏感原文到日志。
- 所有输出都写新文件。
- 临时目录处理完删除，异常时保留最近一次用于排查。
- 所有外部命令必须使用参数数组，不拼接 shell 字符串。
- Windows 路径统一使用 `pathlib.Path`。

## 11. 安全注意

- 不支持绕过别人的 PDF 打开密码。
- 用户输入 owner password 时不写日志。
- 处理报告只记录类型、页码、数量，不记录完整身份证号、手机号。
- 如果自动识别失败，必须提示用户人工复核。
