# LocalPDFGuard v1.1 落地开发与冒烟记录

日期: 2026-06-08  
提交范围: GUI 交互、OCR 抽象、批量处理、安全验证、发布流程

## 1. 已落地能力

### GUI 交互

- 框选后可选中。
- 选中框可拖拽移动。
- 选中框可通过 8 个手柄缩放。
- 支持 Delete 删除选中框。
- 支持右键菜单删除选中框。
- 支持首页、上一页、下一页、末页、页码跳转。
- 支持适合宽度、适合整页、缩放预设、Ctrl+滚轮缩放、滚轮滚动、Shift+滚轮横向滚动。
- 处理完成后可打开输出文件、输出目录、处理报告。
- GUI 中文文案已恢复为正常 UTF-8。

### OCR 脱敏

- 新增 `src/pdf_guard/ocr` 模块。
- 新增 `OcrProvider` 抽象。
- 新增 PaddleOCR provider，采用懒加载方式。
- Standard 版未安装 OCR 依赖时仍可正常运行。
- OCR Full 版可通过 `requirements.ocr.lock.txt` 打包 PaddleOCR/PaddlePaddle CPU 依赖。
- OCR 支持手机号、身份证、姓名、地址候选识别。
- 手机号、身份证可作为默认确认框；姓名、地址保持待确认，避免静默误脱敏。
- CLI 增加 `--enable-ocr` 和 `--verify-ocr`。

### 批量处理

- 新增 `src/pdf_guard/batch` 模块。
- CLI 增加 `batch` 子命令。
- 支持多文件/文件夹输入。
- 支持递归扫描。
- 支持失败继续。
- 每个文件输出独立 report JSON。
- 批次输出 `batch.report.json`。
- GUI 增加批量入口和批量选项弹窗。

### 安全验证

- 输出验证报告增加 `PASS/WARN/FAIL` 风险等级。
- 增加权限状态、结构状态、结构告警、清理项记录。
- 增强 metadata、XMP、书签、注释、链接、OpenAction、Names、AcroForm 等结构清理。
- 输出后重新打开 PDF 做文本残留复查。
- 支持可选 OCR 复查。

### 发布流程

- 版本号更新到 `1.1.0-dev`。
- 新增 `requirements.ocr.lock.txt`。
- 新增 Standard/OCR Full 构建脚本。
- Inno Setup 脚本升级到 v1.1.0 命名。
- 新增 GitHub Actions release workflow。
- Release workflow 包含测试、构建、安装包、SHA256、Release 上传。
