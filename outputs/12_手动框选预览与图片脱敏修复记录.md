# 手动框选预览与图片脱敏修复记录

日期：2026-06-07

## 1. 用户反馈

GUI 中已选择两个手动脱敏区域，右侧报告显示：

- `redaction_count: 2`
- `flattened: true`
- `encrypted: true`
- `verification_passed: true`

但中间预览区域看起来仍然没有被覆盖。

## 2. 排查结论

实际排查了截图里的输出文件：

```text
C:\Users\Administrator\Desktop\OTHERS\三上数学 期末真卷-【小张老师专属】_guarded.pdf
```

将第 7 页渲染后确认：两个手动框选区域已经被黑块覆盖。

真正的问题是 GUI 处理完成后仍然渲染原始输入 PDF：

```text
self.input_path
```

因此右侧报告是输出文件结果，中间页面仍显示原文件预览，造成“没有被覆盖”的误判。

## 3. 已修复

### 3.1 GUI 处理后自动预览输出 PDF

处理成功后：

- `preview_path` 自动切换到输出 PDF。
- 清空脱敏框列表。
- 重新渲染当前页。
- 状态提示改为“处理完成，当前预览为输出 PDF”。

### 3.2 图片型/扫描型 PDF 脱敏加固

`apply_redactions()` 改为显式处理图片像素：

```python
page.apply_redactions(
    images=fitz.PDF_REDACT_IMAGE_PIXELS,
    graphics=fitz.PDF_REDACT_LINE_ART_REMOVE_IF_TOUCHED,
    text=fitz.PDF_REDACT_TEXT_REMOVE,
)
```

这可以确保扫描件、整页图片 PDF 中被框选区域会被像素打黑。
