# PRD: LocalPDFGuard v1.1

版本: v1.1  
日期: 2026-06-07  
基础版本: v0.1.0  
运行环境: Windows 10/11 x64，本地离线运行  
产品定位: 面向真实办公场景的本地 PDF 脱敏、水印、权限保护工具

## 1. 版本目标

v1.1 的目标是把 v0.1.0 从“可用的最小版本”升级为“可用于日常办公批量处理的稳定版本”。

核心提升:

- 手动框选脱敏从“能画框”升级为“可编辑、可复核、可纠错”。
- 扫描件从“主要靠人工框选”升级为“本地 OCR 自动识别候选 + 人工确认”。
- 单文件处理升级为多文件批量处理。
- 输出安全性从基础验证升级为文本层、OCR 层、PDF 结构层的组合验证。
- 发布流程从本地手工打包升级为 GitHub Actions 自动构建、自动校验、自动发布。

## 2. 必须实现范围

### 2.1 GUI 交互优化

#### 2.1.1 框选区域可编辑

用户在 PDF 预览区域框选脱敏区域后，可以继续调整该区域:

- 点击选中已有框。
- 鼠标拖拽移动选中框。
- 拖拽边缘或角点缩放选中框。
- 按 `Delete` 删除选中框。
- 右键菜单删除选中框。
- 框列表与预览画布双向同步。
- 显示框来源: 手动、文本规则、OCR。
- 显示框类别: 手机号、身份证、姓名、地址、邮箱、银行卡、自定义、未知。
- 显示框置信度，OCR 候选默认需要用户确认。

验收标准:

- 同一页存在多个框时，选中、拖拽、缩放不会误操作其他框。
- 缩放比例变化后，框的 PDF 坐标不漂移。
- 翻页后再返回，已编辑框保持正确位置。
- 删除框后，处理输出中不再包含该框。

#### 2.1.2 处理完成后的打开动作

处理完成后，在结果区域提供:

- 打开输出文件。
- 打开输出目录。
- 复制输出路径。
- 打开处理报告。

验收标准:

- 输出文件存在时按钮可点击。
- 输出失败时按钮禁用，并显示失败原因。
- 便携版和安装版都可用。

#### 2.1.3 页面缩放、滚动、翻页体验

新增或优化:

- 适合宽度。
- 适合整页。
- 25%、50%、75%、100%、150%、200%、300% 缩放预设。
- `Ctrl + 鼠标滚轮` 缩放。
- 鼠标滚轮纵向滚动。
- `Shift + 鼠标滚轮` 横向滚动。
- 上一页、下一页、首页、末页。
- 页码输入跳转。
- 当前页/总页数显示。
- 缩放时尽量保持鼠标所在位置不跳变。

验收标准:

- 大页面、高 DPI 扫描件、多页 PDF 下滚动不卡死。
- 翻页不会丢失当前文档状态。
- Canvas 滚动区域与页面实际尺寸一致。

### 2.2 OCR 脱敏

v1.1 接入本地 OCR，用于扫描件和图片型 PDF 的敏感信息候选识别。

OCR 范围:

- 手机号。
- 身份证号。
- 姓名。
- 地址。
- 邮箱、银行卡号、统一社会信用代码继续沿用文本规则能力。

识别原则:

- OCR 只生成候选框，不直接静默脱敏。
- 手机号、身份证号可以高置信度默认勾选。
- 姓名、地址误判风险高，默认进入待确认列表。
- 用户必须能看到识别文本、类别、页码、位置和置信度。
- 用户可以取消、调整、删除 OCR 框。

扫描件处理流程:

1. PyMuPDF 渲染页面为图片。
2. OCR 引擎识别图片文字块和坐标。
3. 将 OCR 图片坐标转换为 PDF 页面坐标。
4. 对 OCR 文本应用规则和启发式识别。
5. 生成候选 `RedactionBox`。
6. 用户复核确认。
7. 执行真实脱敏和安全验证。

### 2.3 批量处理

支持多文件和文件夹批量处理。

功能要求:

- 选择多个 PDF。
- 选择文件夹，自动扫描其中 PDF。
- 支持递归扫描开关。
- 批量列表显示文件名、页数、状态、命中数、输出路径、失败原因。
- 单个文件失败不影响后续文件。
- 支持暂停、继续、取消。
- 输出文件默认写入用户选择的输出目录。
- 输出命名默认 `{原文件名}_guarded.pdf`，重名时自动追加序号。
- 每个文件生成单独报告。
- 批次生成总报告。

批量处理的默认策略:

- 默认继承当前界面配置。
- 默认启用已有规则脱敏。
- OCR 批量开关默认关闭，避免第一次使用时耗时过长。
- 用户明确启用 OCR 后，再对扫描件执行 OCR。

### 2.4 安全性优化

v1.1 必须补齐以下安全能力:

- 输出 PDF 文本提取复查。
- 输出 PDF OCR 复查，尤其是扫描件和压平输出。
- 元数据清理。
- XMP 清理。
- 书签/目录清理。
- 注释清理。
- 附件清理。
- 链接清理。
- JavaScript 和 OpenAction 清理。
- 表单字段清理或压平。
- 隐藏对象和增量更新残留风险检查。
- 权限密码和权限位校验。
- 输出风险报告。

风险报告等级:

| 等级 | 含义 | 处理建议 |
|---|---|---|
| PASS | 未发现已知敏感残留 | 可交付，但仍建议人工抽查 |
| WARN | 存在无法自动确认的结构或低置信风险 | 人工复核后再交付 |
| FAIL | 发现明确敏感文本或权限设置失败 | 不允许作为正式输出 |

### 2.5 发布流程优化

v1.1 发布必须自动化:

- GitHub Actions 在 Windows runner 上执行。
- 安装锁定依赖。
- 运行单元测试。
- 运行 CLI smoke test。
- 构建 GUI 便携版 zip。
- 构建安装版 exe。
- 生成 SHA256。
- 创建 GitHub Release。
- 上传 zip、exe、sha256、发布说明。

## 3. 暂不实现范围

以下需求不进入 v1.1:

- 脱敏模板。
- 云 OCR。
- 多人协作审批。
- Web 服务化部署。
- 对 PDF 权限限制提供绝对不可绕过承诺。
- OCR 100% 准确承诺。
- 复杂 NLP 姓名地址识别模型训练。

## 4. 用户流程

### 4.1 单文件流程

1. 打开 PDF。
2. 预览页面。
3. 可选: 自动文本规则识别。
4. 可选: OCR 识别扫描件。
5. 人工确认候选框。
6. 手动补充、拖拽、缩放、删除框。
7. 设置水印、权限、压平、安全清理。
8. 执行处理。
9. 查看报告。
10. 打开输出文件或输出目录。

### 4.2 批量流程

1. 选择多个 PDF 或输入文件夹。
2. 设置统一处理配置。
3. 可选启用 OCR。
4. 执行批量处理。
5. 实时查看每个文件状态。
6. 处理完成后查看总报告。
7. 打开输出目录。

## 5. 成功指标

- 手动框编辑相关操作在 20 页以内常规 PDF 上无明显卡顿。
- OCR 对清晰扫描件中的手机号、身份证号召回率达到可用水平，具体以样本文档验收。
- 批量处理 50 个 PDF 时，单个失败不会中断批次。
- 输出报告能明确说明命中、处理、残留、权限和清理结果。
- GitHub Release 可以由 tag 自动生成，普通用户下载后无需安装 Python 即可运行。
