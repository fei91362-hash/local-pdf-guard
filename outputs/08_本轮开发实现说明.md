# 本轮开发实现说明

日期：2026-06-07  
范围：V1 第一轮 CLI 核心闭环

## 1. 已实现

- Python 项目骨架。
- CLI 入口：`python -m pdf_guard process`。
- 自动识别：手机号、身份证号、邮箱、银行卡号、统一社会信用代码、自定义关键词。
- 真脱敏：PyMuPDF redaction + `apply_redactions()`。
- 中文水印：PyMuPDF CJK 字体 `china-s`，支持透明度、平铺、单水印。
- 安全压平：把处理后页面渲染成图片 PDF。
- 权限密码：pikepdf AES-256 owner password，默认禁止复制、修改、批注、表单、页面组装、打印。
- 验证：输出后重新提取文本检查敏感信息残留，并检查 PDF 加密状态。
- 测试：规则、普通流程、压平流程。
- 冒烟脚本：普通 CLI 和压平 CLI。
- 便携版核心打包脚本：PyInstaller onedir。

## 3. 运行方式

```powershell
.\.venv\Scripts\python.exe -m pdf_guard process `
  --input work\sample_sensitive.pdf `
  --output work\sample_guarded.pdf `
  --owner-password "owner-pass" `
  --watermark "内部资料 禁止外传" `
  --redact-mobile `
  --redact-id-card `
  --redact-email `
  --keyword "Alpha" `
  --report-json work\sample_guarded_report.json
```

压平模式：

```powershell
.\.venv\Scripts\python.exe -m pdf_guard process `
  --input work\sample_sensitive.pdf `
  --output work\sample_guarded_flattened.pdf `
  --owner-password "owner-pass" `
  --watermark "内部资料 禁止外传" `
  --redact-mobile `
  --redact-id-card `
  --redact-email `
  --keyword "Alpha" `
  --flatten `
  --flatten-dpi 100 `
  --report-json work\sample_guarded_flattened_report.json
```
