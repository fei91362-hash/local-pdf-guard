## 3. 本轮发现并修复的问题

### PyMuPDF `insert_text` 不支持 45 度 rotate

现象：

```text
ValueError: bad rotate value
```

处理：

- 改用 `morph` 矩阵支持任意角度文字水印。

### 默认字体不能正确写入中文水印

现象：

- 文本提取里中文水印变成占位点。

处理：

- 水印默认使用 PyMuPDF CJK 字体 `china-s`。

### PyInstaller 直接打包包内 `__main__.py` 相对导入失败

现象：

```text
ImportError: attempted relative import with no known parent package
```

处理：

- 新增 `scripts/local_pdf_guard_core_launcher.py` 作为 PyInstaller 入口。
