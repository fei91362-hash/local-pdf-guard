# PRD：Windows 本地 PDF 脱敏水印权限工具 V1

版本：V1.0  
日期：2026-06-07  
产品代号：Local PDF Guard  
目标用户：需要在 Windows 本机处理敏感 PDF 的个人、行政、法务、财务、运营人员

## 1. 背景

用户需要一个简单的本地工具，对 PDF 做三类处理：

1. 脱敏：隐藏并删除敏感信息。
2. 水印：给 PDF 加内部资料、禁止外传等水印。
3. 权限限制：禁止普通阅读器复制、修改、页面提取。

真实使用环境可能没有 Python、pip、PDF 工具或网络，因此最终交付必须包含所有运行依赖。

## 2. 产品目标

V1 的目标是“小而稳”：

- 操作简单，不要求用户懂 PDF 技术。
- 所有处理在本机完成。
- 自动识别常见敏感信息，但必须允许人工确认。
- 支持手动框选脱敏，解决自动识别漏掉的内容。
- 生成新 PDF，不修改原始文件。
- 输出便携版和安装版。

## 3. 用户场景

### 场景 1：合同对外发送

用户打开合同 PDF，自动识别手机号、身份证号、邮箱、银行卡号，人工框选姓名、地址、金额，输出带水印且限制复制修改的 PDF。

### 场景 2：扫描件截图式脱敏

用户打开扫描版 PDF，自动识别不到文字，用户手动框选敏感区域，选择安全压平输出，得到不可复制底层文字的新 PDF。

### 场景 3：批前人工检查

用户先让工具自动标出疑似敏感内容，逐页确认后执行脱敏，输出前工具再次提取文本检查是否仍存在身份证号、手机号、邮箱。

## 4. 功能范围

### 4.1 PDF 输入

- 支持选择单个 PDF 文件。
- 支持拖拽 PDF 到窗口。
- 如果 PDF 有打开密码，弹出输入打开密码。
- 不支持破解或绕过 PDF 打开密码。

### 4.2 自动脱敏

V1 默认规则：

| 类型 | 示例 | 处理方式 |
|---|---|---|
| 中国手机号 | 13812345678 | 整段真脱敏或替换为 138****5678 |
| 身份证号 | 110101199001011234 | 整段真脱敏或替换为 110101********1234 |
| 邮箱 | name@example.com | 整段真脱敏或替换为 n***@example.com |
| 银行卡号 | 6222020202020202 | 整段真脱敏 |
| 统一社会信用代码 | 18 位代码 | 整段真脱敏 |
| 自定义关键词 | 用户输入 | 整词或模糊匹配 |

自动识别结果只作为候选区域，必须在预览里展示给用户确认。

### 4.3 手动脱敏

- 用户可以在 PDF 预览页用鼠标框选区域。
- 支持删除框选区域。
- 支持调整当前页缩放比例。
- 支持上一页、下一页。
- 支持显示当前页全部待脱敏区域。

V1 不要求复杂编辑能力，例如旋转框、任意多边形框。

### 4.4 真脱敏

执行时必须使用 PDF redaction 机制删除底层内容，而不是只画黑框。

V1 支持两种遮盖样式：

- 黑块：默认。
- 白块 + “已脱敏”文字：可选。

### 4.5 水印

支持文字水印：

- 水印文字，默认“内部资料 禁止外传”。
- 字号。
- 角度，默认 45 度。
- 颜色，默认浅灰。
- 不透明度，默认 0.18。
- 单个大水印或平铺水印。

V1 不做图片水印，放到 V2。

### 4.6 安全压平输出

提供“安全压平输出”开关。

- 开启：脱敏和水印完成后，将每页渲染成图片，再重新生成 PDF。
- 优点：降低底层文字残留和水印被移除的风险。
- 缺点：文件变大，文字不可复制、不可搜索。

高敏感文件推荐默认开启。

### 4.7 权限密码

支持设置 owner password。

默认权限：

- 禁止复制/提取文本。
- 禁止修改。
- 禁止页面提取/重排。
- 禁止批注编辑。
- 禁止表单填写。
- 可选禁止打印。

默认不设置 user password，即用户打开 PDF 不需要输入密码。  
如用户勾选“打开也需要密码”，再设置 user password。

### 4.8 隐藏信息清理

V1 清理：

- 标准 metadata。
- XMP metadata。
- 文档附件。
- JavaScript/action，能清理则清理。
- 非 redaction 必需的临时批注。

书签/目录是否清理提供开关，默认清理，因为书签可能包含敏感标题。

### 4.9 结果验证

输出后自动执行验证：

- 对输出 PDF 提取文本。
- 检查手机号、身份证号、邮箱、银行卡号、统一社会信用代码是否仍存在。
- 检查用户输入的关键词是否仍存在。
- 检查 PDF 是否设置加密和权限。
- 生成处理报告，显示命中数量、脱敏数量、风险提示。

如果开启安全压平输出，文本提取通常为空或仅保留水印文字，验证重点转为 OCR/视觉人工复核。

## 5. 界面设计

V1 采用单窗口三栏布局：

- 左侧：文件、规则、水印、权限设置。
- 中间：PDF 页面预览和框选。
- 右侧：候选脱敏列表、验证结果、执行按钮。

核心按钮：

- 打开 PDF
- 自动识别
- 添加手动框
- 删除选中框
- 执行处理
- 打开输出目录

## 6. 非功能需求

| 项目 | 要求 |
|---|---|
| 本地化 | 全流程离线，不上传文件 |
| 兼容性 | Windows 10/11 x64 |
| 性能 | 100 页普通 PDF 在 2-5 分钟内处理完成，取决于是否压平 |
| 安全 | 不覆盖原文件；异常时保留错误日志 |
| 易用 | 目标电脑无需安装 Python 或依赖 |
| 可维护 | 模块化目录，规则、处理、UI、打包分离 |

## 7. 验收标准

1. 在无 Python、无 pip、无 qpdf 的干净 Windows 机器上可运行。
2. 便携版解压后双击 exe 可用。
3. 安装版安装后开始菜单和桌面快捷方式可用。
4. 对文本型 PDF 能自动识别手机号、身份证号、邮箱。
5. 手动框选区域能被真正遮盖并删除底层内容。
6. 输出 PDF 不包含原始敏感文本。
7. 输出 PDF 带水印。
8. 输出 PDF 设置 owner password 和复制/修改限制。
9. 原始 PDF 不被覆盖。
10. 处理失败时有明确错误提示和日志。

## 8. V1 不承诺

- 不承诺 100% 自动发现所有敏感信息。
- 不承诺权限密码防专业工具绕过。
- 不承诺扫描件能自动识别敏感文字。
- 不承诺保留原 PDF 的所有交互元素、表单、签名。
- 安全压平输出会破坏可复制文字和部分 PDF 结构。
