# 验收测试与安全验证清单

版本：V1.0  
日期：2026-06-07

## 1. 验收目标

验证 V1 工具是否满足：

- 本地运行。
- 目标电脑无依赖可用。
- 真脱敏。
- 水印可见。
- 权限密码生效。
- 不覆盖原文件。
- 异常可追踪。

## 2. 样例文件

需要准备：

| 文件 | 内容 |
|---|---|
| `sample_text_sensitive.pdf` | 包含手机号、身份证号、邮箱、银行卡号 |
| `sample_keyword.pdf` | 包含自定义关键词 |
| `sample_scanned.pdf` | 扫描件图片 PDF |
| `sample_rotated.pdf` | 页面旋转 90/180 度 |
| `sample_large_100_pages.pdf` | 100 页压力测试 |
| `sample_open_password.pdf` | 有打开密码 |
| `sample_damaged.pdf` | 轻微损坏 PDF |

样例文件不能包含真实个人信息，使用测试数据。

## 3. 功能验收

### 3.1 打开文件

- 能选择 PDF。
- 能拖拽 PDF。
- 对非 PDF 给出错误提示。
- 对打开密码 PDF 弹出密码输入。
- 密码错误有明确提示。

### 3.2 自动识别

- 能识别手机号。
- 能识别身份证号。
- 能识别邮箱。
- 能识别银行卡号。
- 能识别统一社会信用代码。
- 自定义关键词可识别。
- 定位失败时不静默跳过，提示人工处理。

### 3.3 手动框选

- 鼠标拖拽能创建脱敏框。
- 能删除脱敏框。
- 翻页后框仍保留。
- 缩放后框位置仍准确。
- 旋转页面上框选位置正确。

### 3.4 真脱敏

处理后：

- 页面视觉上敏感内容被遮盖。
- PDF 文本提取中找不到原始手机号。
- PDF 文本提取中找不到原始身份证号。
- PDF 文本提取中找不到原始邮箱。
- PDF 文本提取中找不到用户关键词。

### 3.5 水印

- 每页都有水印。
- 水印位置正确。
- 水印透明度可接受。
- 压平模式下水印成为页面图像的一部分。

### 3.6 权限密码

- PDF 可打开。
- 普通阅读器中无法复制。
- 普通阅读器中无法修改。
- 页面提取/重排受限。
- owner password 保存成功。
- 如设置 user password，打开 PDF 需要密码。

说明：权限限制依赖阅读器遵守，不作为强安全承诺。

### 3.7 安全压平

- 开启压平后输出 PDF 页面正常。
- 输出文件文字不可复制。
- 输出体积增加在可接受范围。
- DPI 150/200/300 均可运行。

## 4. 依赖验收

在干净 Windows 机器：

- 便携版无需安装 Python。
- 便携版无需安装 qpdf。
- 安装版无需联网。
- 安装版卸载干净。
- 程序能显示依赖版本信息。

## 5. 安全验证

### 5.1 文本提取验证

用工具内部验证器：

```text
verify_output(output.pdf, original_patterns)
```

人工附加验证：

- 用 Adobe Reader 搜索原手机号。
- 用浏览器打开 PDF 搜索原身份证号。
- 用 qpdf 或 pikepdf 检查加密状态。

### 5.2 元数据验证

检查：

- Title 不包含敏感信息。
- Author 不包含敏感信息。
- Subject 不包含敏感信息。
- Keywords 不包含敏感信息。
- XMP metadata 已清理。
- 附件已移除。

### 5.3 日志验证

日志不得包含：

- 完整手机号。
- 完整身份证号。
- 完整银行卡号。
- 完整邮箱。
- owner password。
- user password。

日志可以包含：

- 页码。
- 敏感类型。
- 命中数量。
- hash。

## 6. 性能验收

| 文件 | 目标 |
|---|---|
| 10 页文本 PDF | 30 秒内 |
| 100 页文本 PDF | 5 分钟内 |
| 100 页压平 200 DPI | 10 分钟内，视机器配置 |
| 单页预览切换 | 1 秒内 |

## 7. 失败用例

必须测试：

- 输出目录无权限。
- 输出文件已打开被占用。
- owner password 为空。
- 用户取消处理。
- 中途异常。
- 大 PDF 内存压力。

失败时：

- 不破坏原文件。
- 不留下半成品覆盖最终输出。
- UI 给出明确提示。
- 日志有错误堆栈。
